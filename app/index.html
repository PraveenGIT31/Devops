How To

Run It Yourself

Step-by-step commands to build and deploy this project locally.

01

Clone & Run Locally

git clone https://github.com/PraveenGIT31/Devops.git
cd Devops
open app/index.html
02

Build Docker Image

docker build -t devops-app:latest .
docker run -d -p 8080:80 devops-app:latest
# Visit http://localhost:8080
03

Push to Docker Hub

docker tag devops-app:latest <username>/devops-app:latest
docker push <username>/devops-app:latest
04

Deploy to Kubernetes

minikube start
kubectl apply -f k8s/
kubectl get pods
minikube service devops-service
